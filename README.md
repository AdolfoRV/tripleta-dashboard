# Tripleta Dashboard

The Tripleta Dashboard is a centralized management interface designed to integrate key Google Workspace services. It provides a unified view for Gmail, Google Drive, Calendar, and Tasks to streamline daily productivity.

## Tech Stack
- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)

## Core Features
- **Gmail Integration**: Manage email threads directly from the dashboard.
- **Google Drive Access**: Quick browsing and management of drive files.
- **Calendar Management**: View and track your weekly schedule.
- **Tasks Panel**: Integrated todo-list and task management.

## Getting Started

To set up the dashboard locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/AdolfoRV/tripleta-dashboard.git
   cd tripleta-dashboard
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```

## Deployment
This project is configured for deployment via GitHub Pages:
```bash
npm run deploy
```
